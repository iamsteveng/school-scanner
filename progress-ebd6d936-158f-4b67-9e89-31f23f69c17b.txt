## Codebase Patterns
- Convex mutation handlers can return typed result unions (e.g., `{ ok: true | false, code }`) for frontend-safe branching without parsing error strings.
- `shared/selectionRules.ts` is the shared backend/frontend-friendly policy location for selection gating; keep lock/limit checks there for consistent enforcement.
- Frontend component tests in this repo commonly mock `next/navigation` router methods and `convex/react` hooks, then pass query payloads that avoid unrelated redirect effects.
- Client analytics calls should live behind `src/lib/analytics.ts` and be wrapped in UI-level `try/catch` so tracking failures never block navigation flows.
