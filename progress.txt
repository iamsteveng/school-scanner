## Codebase Patterns
- New external provider integrations in Convex should be implemented as `"use node"` actions plus exported pure helper functions so tests can run without Convex runtime wiring.
- For provider API request tests, inject `fetchImpl` into helpers and assert `URLSearchParams` payload fields directly for deterministic coverage of outbound contracts.
- For backend eligibility gates, return typed `{ ok: false, code: "ineligible", reason, message }` outcomes instead of throwing so frontend callers can branch deterministically.
- For Stripe Checkout lifecycle reconciliation, mirror metadata on both `metadata[...]` and `subscription_data[metadata][...]` so downstream webhook handlers can read consistent linkage fields.
- For rapid-request guards in Convex actions, keep debounce logic in an exported pure helper with injectable time/state and release the lock on provider-call failure to preserve deterministic retries.
- For fixed provider redirect contracts, derive URLs from a canonicalized env origin helper and append fixed path constants so tests can validate success/cancel behavior without Convex runtime mocks.
